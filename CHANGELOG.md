# Изменения

## 2.0.1 — 2026-11-25 — исправления инструкции развёртывания
- Добавлен `requirements-dev.txt` (pytest, httpx): команда проверки тестами из README теперь работает на чистом сервере.
- Docker: в README добавлена подготовка папок `data/` и `logs/` с правами для пользователя контейнера (иначе не сохранялся токен Google).

## 2.0.0 — 2026-11-24 — защита данных клиента

Совместимость: все 29 инструментов и их параметры сохранены; добавлен необязательный параметр `confirm` у опасных инструментов и `shared_with_me` у `search_files`.

**Защита от потери данных**
- `delete_file`: только корзина и только после подтверждения; безвозвратное удаление выключено по умолчанию и возможно только из корзины; удаление папок выключено по умолчанию; корневую рабочую папку удалить нельзя.
- `update_file_content`: Google Docs/Sheets/Slides целиком больше не перезаписываются (раньше CSV стирал все листы и формулы таблицы); для обычных файлов — подтверждение и закрепление прежней версии навсегда.
- `sheets_write`: перезапись непустых ячеек — только с подтверждением, прежние значения/формулы сохраняются в журнал; после записи — проверка ошибок формул (`#ERROR!` и т.п.) с подсказкой про `;`.
- `sheets_clear`: только конкретный диапазон, с подтверждением и копией в журнал.
- `docs_replace_text` / `docs_replace_many`: удаление текста и массовые замены (>20 мест) — с подтверждением; отклоняются фрагменты из 1 символа; защита от одновременной правки документа.
- Docs/Sheets-инструменты проверяют тип файла (не применяются к docx/xlsx по ошибке).

**Защита доступа**
- Доступ «всем по ссылке» запрещён по умолчанию; передача владения запрещена; выдача и отзыв доступа — с подтверждением; доступ владельца отозвать нельзя.
- Режим «только чтение» (`GDRIVE_READ_ONLY`), жёсткое ограничение папками (`GDRIVE_ALLOWED_FOLDER_IDS`).
- HTTP-сервер не запускается без `MCP_AUTH_TOKEN` (≥24 символа); сравнение токена в постоянное время.

**Надёжность**
- Отдельный клиент Google API на каждый поток (раньше общий — сбои при параллельных запросах).
- Повторы при 429/5xx только для безопасных операций; таймаут 60 с; понятная ошибка при отзыве доступа Google.
- Журнал всех изменений `logs/audit.log` с ротацией.
- MCP-аннотации инструментов (`readOnlyHint` / `destructiveHint`).
- Зафиксированы версии библиотек (`requirements.txt`, `requirements.lock`); Docker — без root, healthcheck; systemd — с ограничением прав.
- 41 автотест (`tests/`).
